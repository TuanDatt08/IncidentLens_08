# VPS + Neon + Vast.ai Implementation Plan

Goal: prepare the user-approved architecture; preserve frontend and inference contracts.
Execution: inline, no external purchases or deployments without infrastructure details.

Design: frontend/API/worker stay on VPS, files on persistent VPS volume, SQL on Neon.
Only Ollama inference runs on Vast.ai. An authenticated SSH tunnel exposes remote Ollama
as a loopback endpoint inside the app network namespace; existing schema/evidence validation stays active.
The website starts without GPU; worker readiness gate checks GPU before claiming jobs.
GPU stopping during inference remains a failed job using existing behavior, not automatic exactly-once resume.
Manual GPU start/stop first; automatic purchasing/start-stop is out of scope until a budget is specified.
