# Galaxy orbit refinement

## Ambient space follow-up

The next refinement adds six small orbiting space objects: two crystals, two luminous wire cubes, a probe and a moon. Mobile hides the two small variants. They share the existing panel animation loop with distinct 21–39 second periods, inclined paths, self rotation and depth ordering. There is no additional render loop or library. Shapes are local CSS geometry and are hidden from accessibility semantics.

Artwork throughout the landing now floats gently: demo image/chart, workflow illustration, capability data clusters, handoff core and final halo. Independent CSS translate/rotate avoids replacing existing scroll transforms. Reading columns, navigation and controls stay stable. Intersection observers pause these loops outside the viewport, the root visibility handler pauses them in hidden tabs, and reduced motion removes ambient animation. Background star drift and nebula breathing are more perceptible while remaining subtle.

The user requested more believable car imagery and a stronger feeling of floating through space, with Video, Telemetry and Evidence revolving around the planet. The reference https://p-136.vercel.app/ was observed in the browser: it uses photographic scene thumbnails, floating interface layers, varied focus/depth and a quiet reading region. Its assets, claims and application behavior were not copied.

The landing keeps its Galaxy direction. Three camera-facing panels follow a projected elliptical orbit with a 32-second period, scale/opacity/depth ordering and a maximum 30 updates per second. One DOM animation loop updates transforms without React renders. It pauses offscreen and when the document is hidden; reduced motion preserves the static composition. Mobile uses narrower radii. The larger WebGL planet has rotating turbulent cloud material, a stable light direction and a stronger atmospheric halo. The existing one-pass renderer, lazy load, pixel caps and SVG fallback remain.

The built-in imagegen tool generated a photographic synthetic dashcam image, now stored at `frontend/public/landing/dashcam-demo-v2.webp` (1280px wide, approximately 100 KB). It is an illustrative still across all demo moments, not footage or evidence from a real incident. The demo explicitly identifies this limitation. The original PNG is retained in the imagegen output directory; the project uses a compressed local WebP.
